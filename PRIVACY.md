# Privacy Policy

labor.fun is a framework for running a self-hosted AI assistant for an
organization. Each deployment is operated by that organization, on its own
server, for its own members. This policy describes what a labor.fun assistant
accesses and what it does with that data.

## What the assistant accesses

- **Chat messages** in the channels, groups and direct messages it has been
  added to (for example Discord, Slack or Telegram).
- **Google Workspace data** for the assistant's own Google account, when the
  operator connects one: Gmail, Calendar, Drive, Docs, Sheets and Tasks. It
  can only see files and calendars that belong to that account or that have
  been shared with it.
- **Other connected services** the operator enables, such as GitHub or Linear.

## How the data is used

Data is used only to do what the organization's members ask of the assistant:
answer questions, draft and edit documents, schedule events, triage email and
keep the organization's knowledge base up to date.

The assistant's replies are generated by a large language model. The text
needed to answer a request is sent to the model provider the operator has
configured, and is subject to that provider's terms.

## Storage and sharing

- Conversations, the knowledge base and logs are stored on the operator's own
  server.
- Data is not sold, not used for advertising, and not shared with anyone
  outside the organization except the model provider described above.
- Credentials for connected services are stored on the operator's server and
  are never written to chat or committed to source control.

## Google user data

The assistant's use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements. Google data is used only to provide the
features described above, and labor.fun does not use it to train AI models.

## Revoking access and deleting data

- To remove the assistant's access to a Google account, revoke it at
  [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
- To have conversation history or knowledge-base entries about you deleted,
  ask the organization that runs the assistant.

## Contact

For questions about a specific deployment, contact the organization that runs
it. For questions about the framework, open an issue at
[github.com/BreadchainCoop/labor.fun](https://github.com/BreadchainCoop/labor.fun/issues).
